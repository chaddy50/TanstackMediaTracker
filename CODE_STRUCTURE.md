# Code Structure
This is a TanStack Start app (React 19 + TanStack Router, server-rendered) backed by Postgres through Drizzle ORM. The main entry point is `src/router.tsx`.

Beyond that, the app is broken up into seven main directories under `src`.

## routes
Contains every URL in the app using TanStack Router's file-based routing. Route files are thin: each declares its URL, loader, and search validation, then points at a screen from `features/screens`.

Routes are organized by layout using pathless layout routes:
1. **_auth** - public pages (login, forgot password, reset password).
2. **_authenticated** - everything behind auth. Its `beforeLoad` checks the session to see if there's a user currently logged in and redirects to `/login` if there isn't.
3. **_authenticated/_app** - main screens with sidebar and bottom nav.
4. **_authenticated/_details** - drill-in screens without the sidebar and bottom nav.

## features
**screens** - contains the UI for screens that the user can navigate to.

Other sub-folders contain other core features of the app, such as filtering and sorting views, searching for new media items, and navigating the application.

The `mediaItemSearch` feature also contains the `api` directory with the clients for external metadata providers (Hardcover, TMDB, IGDB, iTunes, etc.).

## components
Contains shared components used across the application. 

The `ui` subfolder contains the shadcn/Radix primitives.

## lib
Contains framework-agnostic helpers with no server or React dependency.

## database
Contains the single source of truth for the database. 

`schema.ts` defines the tables and `index.ts` exports the Drizzle client. 

Migrations live in `/drizzle` and are generated by drizzle-kit.

## integrations
Contains the TanStack Query client setup used by the router.

## i18n
Contains all user-facing strings in `locales/en.ts` with type-checked `t()` calls.
